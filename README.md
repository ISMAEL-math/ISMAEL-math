## 🔬 研究与实战 (Research & Projects)

* **[California Housing AI Analysis](https://github.com/ISMAEL-math/California-Housing-AI-Analysis)**
  * **课题内容**：基于 Scikit-learn 对加州 20,000+ 房产观测值进行回归建模与预测。
  * **数学实践**：
    * **数据清洗**：识别并处理了响应变量在 $5.0$ 处的截断观测值，恢复了数据分布的统计有效性。
    * **模型拟合**：应用最小二乘法原理拟合高维线性超平面，深入分析特征变量间的线性相关性。
  * **成果**：模型解释力 ($R^2$) 达到 **0.5689**，验证了收入中位数与资产定价的强相关逻辑。
